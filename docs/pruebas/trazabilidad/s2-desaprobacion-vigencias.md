# Trazabilidad S2: desaprobación, reintegro, reintento, retiro de versión, vínculo en revisión, revalidaciones, exención y vigencias

Lote S2 de la conversión de las e2e a pruebas normales (decisión PC-1). Cada fila dice qué comprobaba la e2e retirada y qué prueba de dominio, API o Vitest lo cubre ahora.
Formato y reglas en `LEEME.md`. Las pruebas nuevas de este lote son `DetalleExpediente.devolucion.test.tsx`, `TarjetaExpedienteVinculo.rechazo.test.tsx`, `DetalleVinculo.test.tsx`,
`ExencionDeRequisito.test.tsx`, `PaginaExpediente.documentos.test.tsx`, `ExpedientesApiTests.DesaprobacionDesdeEtapa.cs` y `RequisitosExencionYLoteApiTests.cs`; el resto son aserciones agregadas a pruebas que ya existían.

Las mutaciones de las filas de desaprobación, reintegro y reintento las hizo quien escribió las pruebas sobre el código anterior a la ficha por sectores. Al traerlas a la rama actual se repitieron sobre el código vigente las del detalle del expediente (aviso de devolución, «Más acciones», «Expediente aprobado», «Reabrir la etapa» sin permiso), la de las acciones del vínculo que no avisan, la de la tarjeta del vínculo rechazado y la de desaprobar desde una etapa elegida; las filas con mutaciones de dominio y de API no repetidas (desvincular, reintegrar, certificado) conservan lo que se anotó entonces.
